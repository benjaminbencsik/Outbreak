# OUTBREAK

OUTBREAK is a mobile-first top-down zombie survival game prototype.

## Current systems
- Continuous open-world infected spawning (no waves)
- Zombies and hostile raiders
- Weather and visibility
- Base building and crafting
- Gunsmithing and weapon crafting
- XP and leveling
- Vehicles
- Hidden monument exploration, starting with the Airfield
- Touch controls with desktop keyboard/mouse fallback

## Planned survival systems
- Hunting and wildlife
- Fishing
- Berry bushes and edible wild plants
- Nut-bearing trees
- Food, hunger, cooking, and survival resources
- More monuments and biome variety
- Save/progression system

## Development
The browser build is the current prototype. The longer-term plan is to package OUTBREAK as a downloadable mobile game once the core systems are stable.
